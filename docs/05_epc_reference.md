# EPC reference: quirks and region differences (England & Wales vs Scotland)

This reference lists every EPC variable documented in
[`data/reference/serl_epc_data_dictionary_edition07.csv`](../data/reference/serl_epc_data_dictionary_edition07.csv)
(the real SERL edition07 schema, 103 variables) and states whether it is available for
England & Wales, for Scotland, or both — plus whether the mock pipeline currently
generates it (`src/serl_mock/generator_contextual_data.py`, `_epc_fields()` /
`generate_epc()`).

## Why this matters

The real SERL EPC dataset merges two different national EPC formats. Per the SERL EPC
technical documentation (`docs/documentation/SERL/8666_serl_epc_documentation_edition07.pdf`,
p.1):

> "There are some differences between the English and Welsh EPCs versus the Scottish
> EPCs, both in terms of the variables available and the structure of the data. In
> particular, for the Scottish data if there are multiple types of an element in a
> dwelling then these are recorded in the relevant column and separated by '|'
> [ASCII (decimal) 124], whereas only one type is recorded per element for England
> and Wales."

This produces three distinct patterns, each represented below:

1. **Region-exclusive columns** — 22 variables only exist for Scotland (e.g.
   `dataZone`, `typeOfAssessment`), 7 only for England & Wales (e.g. `localAuthority`,
   `wallsEnergyEff`). Some of these are parallel "twin" columns for the same concept
   under different names (`wallsEnergyEff` vs `wallEnergyEff`, `heatLossCorridor` vs
   `heatLossCorridoor` — the double-`o` is a genuine typo in the source SERL data).
2. **Shared columns, different value vocabulary** — a handful of "All"-region columns
   use a different value format per nation for the same underlying concept
   (`glazedArea`, `constructionAgeBand`, and the multi-element `|` convention on
   `floorEnergyEff`/`roofEnergyEff`).
3. **Shared columns, same vocabulary** — the majority of columns (numeric costs,
   ratings, descriptions, etc.) behave identically regardless of nation.

The mock generator currently only implements pattern 3 fully, plus 4 of the pattern-2
fields (`glazedArea`, `constructionAgeBand`, `floorEnergyEff`, `roofEnergyEff`). The 22
Scotland-only columns are documented in the dictionary but not yet produced by
`generate_epc()` — see the **Generated** column below.

## Legend

- **England & Wales** / **Scotland** — `Yes`/`No`: whether the variable is populated
  (non-null) for records of that nation in the real dataset.
- **Generated** — `Yes`/`No`: whether this variable is included in the mock data
  generator (`_epc_fields()` in `generator_contextual_data.py`).
- **Notes** — special cases: different value vocab by region, region-exclusive twin
  columns, known generator/dictionary gaps, and fields that are only populated under
  specific conditions (e.g. `airTightnessEnergyEff` is Scotland-only and only populated
  for SAP assessments of new-build properties, not RdSAP assessments of existing
  dwellings). Fill-rate / share-of-PUPRN statistics are intentionally omitted here
  pending a check against the actual SERL data.
